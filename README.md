# Blind Color Match
Match the colors. Based on a tiktok video. Made completely with Codex. 

## Run locally
1. Clone the repo
2. `yarn install`
3. `yarn dev`

### Prompt
`your task is to make a simple react spa. in this we will make a blind color matching game. there will be 8 colors
users see and seven hidden colors. users can swap around the visible colors 1 at a time. we will see a counter for
matching colors. initially it should be 0. they shouldn't be matching when the game starts when user moves around and
if it matches, the count of the colors that match are shown. only when all the colors are matched the hidden colors
are revealed and the game ends. we will also count the number of steps the user took. the colors should be random for
each reload of the page.`
